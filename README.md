# Feedback Productions — Arquivo Histórico

Arquivo histórico do website original da Feedback Productions, anteriormente alojado em `https://estudiofeedback.weebly.com/`.

## Conteúdo

- Cópia local do website obtida através do HTTrack.
- Páginas históricas: início, eventos, galeria, vídeos, contactos, apresentação e Festival Sigmanergia.
- Imagens, cartazes, fontes, folhas de estilo e recursos associados ao website original.
- Recursos locais necessários para consultar e estudar a estrutura histórica do site.

## Notas

- Este repositório preserva o website antigo; não é a versão do novo website.
- O espelhamento pode estar incompleto devido a recursos externos ou filtros de transferência.
- Os vídeos externos são preservados através das referências existentes no conteúdo; não são redistribuídos neste arquivo.
- Os registos, cookies e caches potencialmente sensíveis do HTTrack são excluídos do Git.
- Alguns ficheiros auxiliares que continham apenas páginas de erro 404 foram removidos da cópia de trabalho.
- A cópia original do HTTrack deve ser mantida separadamente e não modificada durante este processo.

## Objetivo

Preservar o conteúdo histórico como referência para reconstruir o novo website da Feedback Productions num repositório separado.
